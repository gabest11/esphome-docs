CC1101 Low-Power Sub-1 GHz RF Transceiver
=========================================

.. seo::
    :description: Instructions for setting up CC1101 RF Tranceiver
    :image: cc1101.jpg
    :keywords: cc1101

The ``CC1101 RF Tranceiver`` (`datasheet <https://github.com/gabest11/datasheet/blob/main/CC1101.pdf>`__) can be used together 
with the ``remote_transmitter`` and ``remote_receiver`` components to communicate over free to use frequencies 
like 433.92 or 868 MHz. 

Tested frameworks are Arduino and ESP-IDF but it might work with others.

.. figure:: images/cc1101-full.jpg
    :align: center
    :width: 50.0%

    CC1101 boards.

On ESP8266, you can use a single pin instead of GD0O and GD02 (gdo0_pin is an optional parameter). If assigned,
the pin direction will be reversed for the transfers.

On ESP32, this will not work, you must connect two separate pins. remote_transmitter to GDO0, remote_receiver to GDO2.
If only trasmitting works, they are probably swapped.

The ESP8266 can also work with two separate pins. If no gdo0_pin is given, that is the default mode.

Example configuration for ESP8266
---------------------------------

.. code-block:: yaml

    spi:
      clk_pin: D5
      miso_pin: D6
      mosi_pin: D7
    
    cc1101:
      id: transceiver
      cs_pin: D8
      gdo0_pin:
        number: D1
        allow_other_uses: true
      tuner:
        frequency: 433920

    remote_transmitter:
      pin:
        number: D1  # GDO0
        allow_other_uses: true
      carrier_duty_percent: 100%
      on_transmit:
        then:
          - cc1101.begin_tx: transceiver
      on_complete:
        then:
          - cc1101.end_tx: transceiver

    remote_receiver:
      pin:
        number: D1  # GDO0
        allow_other_uses: true
      dump:
        - rc_switch
      tolerance: 50%
      buffer_size: 1kB
      filter: 250us

Example configuration for ESP32
-------------------------------

Based on a generic nodemcu-32s board.

.. code-block:: yaml

    spi:
      clk_pin: GPIO18
      miso_pin: GPIO19
      mosi_pin: GPIO23
    
    cc1101:
      id: transceiver
      cs_pin: GPIO5
      tuner:
        frequency: 433920

    remote_transmitter:
      pin: GPIO32  # GDO0
      carrier_duty_percent: 100%
      on_transmit:
        then:
          - cc1101.begin_tx: transceiver
      on_complete:
        then:
          - cc1101.end_tx: transceiver

    remote_receiver:
      pin: GPIO33  # GDO2
      dump:
        - rc_switch
      tolerance: 50%
      buffer_size: 2kb
      filter: 250us

Full configuration with default values
--------------------------------------

.. code-block:: yaml

    cc1101:
      id: transceiver
      cs_pin: ..
      gdo0_pin: ..
      output_power: 11
      rx_attenuation: 0dB
      dc_blocking_filter: True
      tuner:
        frequency: 433920
        if_frequency: 153
        bandwidth: 203
        channel: 0
        channel_spacing: 200
        # fsk_deviation: 47.607
        # msk_deviation: 0
        symbol_rate: 5000
        modulation: ASK/OOK
      agc:
        magn_target: 42
        max_lna_gain: Default
        max_dva_gain: Default
        carrier_sense_abs_thr: 0
        carrier_sense_rel_thr: Default
        lna_priority: True
        filter_length_fsk_msk: 16
        filter_length_ask_ook: 8dB
        freeze: Default
        wait_time: 16
        hyst_level: Medium
      sensor:
        chip_id:
          name: CC1101 Chip Id
        rssi:
          name: CC1101 RSSI
        lqi:
          name: CC1101 LQI
        temperature:
          name: CC1101 Temperature


- **cs_pin** (**Required**, :ref:`config-pin`): SPI chip select pint.
- **gdo0_pin** (*Optional*, :ref:`config-pin`): Bi-directional pin for ESP8266.
- **output_power** (*Optional*, float): -70 to 11. In dBm.
- **rx_attenuation** (*Optional*, enum): 0dB, 6dB, 12dB, 18dB.
- **dc_blocking_filter** (*Optional*, boolean): Digital DC blocking filter before demodulator. True: better sensitivity, False: current optimized, only for data rates below 250 kBaud.
- **frequency** (*Optional*, float): Valid range is 300000 to 928000 kHz.
- **if_frequency** (*Optional*, float): Intermediate frequency. 25 to 788 kHz.
- **bandwidth** (*Optional*, float): Sets the decimation ratio for the delta-sigma ADC input stream and thus the channel bandwidth. 58 to 812 kHz.
- **channel** (*Optional*, uint8_t): Channel offset relative to frequency. Always in the positive direction.
- **channel_spacing** (*Optional*, float): This is added to the frequency, `channel` number of times. 25 to 405 kHz.
- **fsk_deviation** (*Optional*, float): TX: Specifies the nominal frequency deviation from the carrier. RX: Specifies the expected frequency deviation from the incoming signal, must be approximately right for the demodulator to be performed reliably and robustly.
- **msk_deviation** (*Optional*, int): Tx: Specifies the fraction of symbol period (N/8) during which a phase change occurs. RX: no effect.
- **symbol_rate** (*Optional*, int): 600 to 500000 Baud.
- **modulation** (*Optional*, enum): 2-FSK, GFSK, ASK/OOK, 4-FSK, MSK.
- **magn_target** (*Optional*, enum): 24dB, 27dB, 30dB, 33dB, 36dB, 38dB, 40dB, 42dB. Sets the absolute RSSI threshold for asserting carrier sense. Lowering this can improve range, but will also let thought more noise.
- **max_lna_gain** (*Optional*, enum): Default, 2.6dB, 6.1dB, 7.4dB, 9.2dB, 11.5dB, 14.6dB, 17.1dB. Sets the maximum allowable LNA + LNA 2 gain relative to the maximum possible gain.
- **max_dva_gain** (*Optional*, enum): Default, -1, -2, -3. Reduces the maximum allowable DVGA gain.
- **carrier_sense_abs_thr** (*Optional*, int): -8 to 7. Sets the absolute RSSI threshold for asserting carrier sense.
- **carrier_sense_rel_thr** (*Optional*, enum): Default, +6dB, +10dB, +14dB. Sets the relative change threshold for asserting carrier sense.
- **lna_priority** (*Optional*, boolean): Selects between two different strategies for LNA and LNA 2 gain adjustment. When `True`, the LNA gain is decreased first. When `False`, the LNA 2 gain is decreased to minimum before decreasing LNA gain.
- **filter_length_fsk_msk** (*Optional*, enum): 8, 16, 32, 64. Sets the averaging length for the amplitude from the channel filter.  
- **filter_length_ask_ook** (*Optional*, enum): 4dB, 8dB, 12dB, 16dB. Sets the OOK/ASK decision boundary for OOK/ASK reception.
- **freeze** (*Optional*, enum): Default, On Sync, Analog Only, Analog And Digital. Control when the AGC gain should be frozen.
- **wait_time** (*Optional*, enum): 8, 16, 24, 32. Sets the number of channel filter samples from a gain adjustment has been made until the AGC algorithm starts accumulating new samples.
- **hyst_level** (*Optional*, enum): None, Low, Medium, High. Sets the level of hysteresis on the magnitude deviation (internal AGC signal that determine gain changes).
- **chip_id** (*Optional*): PPVV where PP is the part number, VV is the version.
- **rssi** (*Optional*): RSSI sensor. Value in dBm. The RSSI value is an estimate of the signal power level in the chosen channel. See datasheet 17.3 for further information.
- **lqi** (*Optional*): Link Quality Indicator sensor. The Link Quality Indicator is a metric of the current quality of the received signal. See datasheet 17.6 for further information.
- **temperature** (*Optional*): Integrated temperature sensor. It is not possible to read as of now. GDO0 has to function as an ADC pin.

.. note::

    `fsk_deviation` and `msk_deviation` use the same register, just like `filter_length_fsk_msk` and `filter_length_ask_ook`, do not set both.

Direct control through entities in HA
-------------------------------------

.. code-block:: yaml


    number:
      - platform: cc1101
        output_power:
          name: Output output_power
        tuner:
          frequency:
            name: Tuner frequency
          if_frequency:
            name: Tuner if_frequency
          bandwidth:
            name: Tuner bandwidth
          channel:
            name: Tuner channel
          channel_spacing:
            name: Tuner channel_spacing
          fsk_deviation:
            name: Tuner fsk_deviation
          msk_deviation:
            name: Tuner msk_deviation
          symbol_rate:
            name: Tuner symbol_rate
        agc:
          carrier_sense_abs_thr:
            name: AGC carrier_sense_abs_thr

    select:
      - platform: cc1101
        rx_attenuation:
          name: Input rx_attenuation
        tuner:
          modulation:
            name: Tuner modulation
        agc:
          magn_target:
            name: AGC magn_target
          max_lna_gain:
            name: AGC max_lna_gain
          max_dva_gain:
            name: AGC max_dva_gain
          carrier_sense_rel_thr:
            name: AGC carrier_sense_rel_thr
          filter_length_fsk_msk:
            name: AGC filter_length_fsk_msk
          filter_length_ask_ook:
            name: AGC filter_length_ask_ook
          freeze:
            name: AGC freeze
          wait_time:
            name: AGC wait_time
          hyst_level:
            name: AGC hyst_level
    
    switch:
      - platform: cc1101
        dc_blocking_filter:
          name: Input dc_blocking_filter
        agc:
          lna_priority:
            name: AGC lna_priority

.. note::

    Putting everything into the config can increase memory use by 10k.

Detect a magnetic window sensor
-------------------------------

.. code-block:: yaml

    binary_sensor:
      - platform: remote_receiver
        name: "Window"
        rc_switch_raw:
          code: '110111110001111011100110'
        filters:
          - delayed_off: 1000ms

Transmit a message using the button component
---------------------------------------------

.. code-block:: yaml

    button:
      - platform: template
        name: "Gate"
        on_press:
          - remote_transmitter.transmit_rc_switch_raw:
              code: '0111000110010011110110010100011111110001001011110111'
              protocol:
                pulse_length: 434
                sync: [1,6]
                zero: [1,2]
                one: [2,1]
                inverted: true
              repeat:
                times: 10
